1.2 NumPy
Qué es: Librería para cálculo numérico eficiente y arreglos multidimensionales (Numerical Python).

Ventaja sobre listas Python: almacena datos en memoria continua y opera sobre todos los elementos simultáneamente.

Capacidades:

Arreglos multidimensionales (ndarray)
Operaciones matemáticas vectorizadas
Álgebra lineal y números aleatorios
Base para Pandas, Scikit-learn y SciPy

import numpy as np

1.4 rpy2
Qué es: Librería que integra R dentro de Python.

Cuándo usarla: cuando se necesitan métodos estadísticos avanzados disponibles en R (estadística epidemiológica, modelos estadísticos).

Capacidades: ejecutar código R desde Python, usar paquetes de R, intercambiar datos entre Pandas y R.

1.5 Scikit-learn
Qué es: Librería estándar para machine learning en Python.

Modelos disponibles: clasificación, regresión, clustering, reducción de dimensionalidad.

Herramientas adicionales: preparación de datos, evaluación de modelos, validación cruzada.

Ejercicio — Predecir tipo de defunción (natural vs. violenta):

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

data = pd.read_csv("defunciones_mexico.csv")

X = data[["edad"]]
y = data["tipo_defuncion"]

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

modelo = DecisionTreeClassifier()
modelo.fit(X_train, y_train)
print(modelo.predict(X_test))
